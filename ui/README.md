# Facility view and UI

Owner: Ethan Meza (`ethnmz`).

This folder is the interactive 3D view of the fictional facility and the UI around it. Scope is racks, cooling, and backup power. A person can select one piece of equipment or one planned task, see the affected equipment highlighted, and reset the demo.

The view is read-only. It is not a validated engineering simulation and it does not clear work. Event storage, extraction, deploy, and the contract proposal live in other owners' folders. No rendering library or app framework is chosen. The selection shape is the draft in `contracts/PROPOSAL.md`. Ask Diego on the board before changing that shape.
