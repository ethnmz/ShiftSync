# Transcription and extraction

Owner: Akshi Biswal (`GITHUB_LOGIN_AKSHI`). Replace that placeholder with the real GitHub login before anyone mentions Akshi.

This folder turns synthetic voice transcripts, vendor emails, and maintenance records into proposed equipment events, and writes explanations that quote the source excerpt they came from. Inputs stay synthetic. Every emitted event keeps at least one source.

No model, vendor, or API is chosen. Nemotron and any other named model are optional ideas, not a requirement. Do not install one. This folder does not store the system of record, run the dependency checks, or clear tasks. The event shape is the draft in `contracts/PROPOSAL.md`. Ask Diego on the board before changing it.
